# 🎯 AchieveIt — Student Life OS

AchieveIt is a comprehensive student productivity and life management web application built using pure HTML, CSS, and JavaScript.

Designed specifically for students, AchieveIt goes beyond traditional task management by integrating academic planning, exam tracking, goal setting, attendance monitoring, productivity analytics, focus timers, and personalized study insights into a single platform.

---

## ✨ Features

### 📋 Smart Task Management

* Create, edit, delete tasks
* Mark tasks as completed
* Important task highlighting
* Progress tracking
* Due date and time management
* Category-based organization
* Search and filter functionality
* Overdue task detection

### 🎯 Goal Management

* Create long-term and short-term goals
* Track goal progress
* Target date management
* Goal categorization
* Daily action planning

### 📚 Academic Schedule Management

* Semester timetable management
* Attendance tracking
* Subject organization
* CSV schedule import support
* Attendance risk monitoring

### 📝 Exam Tracker

* Store upcoming exams
* Exam countdown system
* Preparation progress tracking
* Syllabus management
* Smart reminders

### 📊 Daily Productivity Dashboard

* Daily performance score
* Productivity analytics
* Progress visualization
* Activity heatmap
* Personalized productivity insights

### ⏱ Focus Timer

* Built-in study timer
* Session tracking
* Productivity enhancement tools

### 🌙 User Experience

* Fully responsive design
* Light/Dark mode
* Modern UI
* Local Storage support
* Smooth animations
* Mobile-friendly layout
